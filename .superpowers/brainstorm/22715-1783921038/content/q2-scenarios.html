Q2: 核心使用场景是什么？

目标：技术爱好者 / 个人开发者。你最想用它解决哪类问题？（可多选）

A

日常效率自动化

定时爬取信息 → AI 总结 → 推送到微信/飞书/邮箱；监控 GitHub Trending → 筛选 → 发送日报

B

内容生产流水线

选题 → 大纲 → AI 撰写 → 配图 → 多平台发布；视频脚本 → 配音 → 字幕生成一条龙

C

数据处理 & 分析

接入数据库/API → AI 分析 → 生成报告/图表；批量文件处理、ETL 管道、自动化报表

D

多 Agent 协作 / 复杂决策

多个 AI Agent 分工协作：一个搜索、一个分析、一个撰写；条件分支、循环、人工审批节点

E

通用型 — 以上都要

不做特定场景限制，提供足够灵活的底层能力，让用户自己搭建任何工作流
